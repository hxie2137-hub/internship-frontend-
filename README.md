# 在韩留学生二手交易平台

一个使用 HTML、CSS 和 JavaScript 开发的前端练习项目，面向在韩留学生的二手商品发布和管理场景。

## 功能

- 登录和退出登录
- 未登录不能发布商品
- 发布商品，填写名称、价格、描述、联系方式和分类
- 搜索商品
- 按分类筛选商品
- 只查看当前用户发布的商品
- 按价格从低到高或从高到低排序
- 标记商品为已售出
- 只能修改或删除自己发布的商品
- 使用 localStorage 保存商品数据，刷新页面后数据仍然保留

## 技术

- HTML
- CSS
- JavaScript
- DOM 操作
- localStorage 本地存储

## 项目亮点

- 使用数组统一管理商品数据，再通过渲染函数更新页面
- 使用 localStorage 实现前端本地数据持久化
- 实现了简单的用户权限逻辑：当前用户只能操作自己发布的商品
- 将商品展示从普通列表升级为商品卡片，提高可读性

## 说明

这是一个前端学习作品，目前数据保存在浏览器本地。如果用于真实平台，需要接入后端接口、数据库和真实登录系统。
